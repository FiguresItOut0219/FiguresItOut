# 样品标注室

访问 `/tools/sample-annotation`，或从首页进入「样品标注室」。

1. 在模型设置中选择 Qwen3.7 Flash / DeepSeek，输入对应 API Key。
2. 默认 Qwen 北京接口；如使用其他地域或兼容服务，修改完整的 Chat Completions 接口地址和模型名称。
3. 上传 JPG、PNG 或 WebP（15 MB、2400 万像素以内），可填写已知材料等补充信息。
4. 点击识别，模型生成材料、颜色、样式、英文描述及归一化坐标。
5. 修改描述、拖动红色编号与端点，逐项确认。编辑后该项恢复待确认。
6. 全部确认后导出原图尺寸的标注 PNG，以及独立的英文描述 TXT。

Key 仅保存在当前页面内存中，不写入本地存储、源码或导出文件。刷新或离开页面会清除当前工作。前端直接访问用户指定的 HTTPS 接口，接口必须允许浏览器跨域访问。若服务不允许跨域，应接入受控后端代理；不要关闭浏览器安全保护。

图片材料判断是外观推测，实际材料成分需人工结合产品资料确认。编号由数组顺序自动生成，删除后自动重排。模型定位与材料描述需人工校对。

验证：`npm run build`；`npx tsx --test tests/sample-analysis.test.ts`。真实模型识别需要有效 API Key，不包含虚构识别结果。
